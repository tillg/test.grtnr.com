Layout Rules & Dimensions

Reference Books (Industry Standards)

  • Neufert – Bauentwurfslehre / Architects’ Data – The definitive German reference for architectural planning. Contains comprehensive metric data on room sizes, clearances, and human dimensions. Based on DIN standards. 44th German edition (2024) available.
  • Metric Handbook (Pamela Buxton) – PDF | UK equivalent to Neufert. Covers all building types with metric planning data.

Online Resources (European/Metric)

  • First in Architecture – Metric Data Design Guide – PDF | Website Excellent UK resource with comprehensive metric data. Contents:
  • 01: Average Standing Dimensions
  • 02: Average Sitting Dimensions
  • 03: Average Wheelchair User Dimensions
  • 04: Circulation and Space
  • 05: Approach, Entrance and Horizontal Circulation
  • 06: Wheelchair Accessible Dwelling Circulation
  • 08: Standard Furniture Sizes
  • 09: Kitchen Standard Sizes
  • 10: Kitchen Standards for Wheelchair Users
  • 11: Accessible Bathrooms and WC’s
  • Plan7Architect – Room Size Guide – https://plan7architect.com/room-size-guide-how-big-should-rooms-be-ai2/ European room size recommendations in m².
  • Style Within – Standard Dimensions (UK) – https://www.stylewithin.co.uk/2017/07/20/standard-dimensions-interior-design/ Interior design dimensions in metric.
  • MDPI – Housing Spaces in Nine European Countries – https://www.mdpi.com/1660-4601/18/8/4278 Academic comparison of dimensional requirements across Europe.

German Building Regulations

  • Wohnflächenverordnung (WoFlV) – German living space calculation standard. Key rules: rooms under 1m height = 0%, 1–2m = 50%, balconies = 25–50%.
  • DIN 277 – Alternative calculation method counting all areas at 100%.
  • Landesbauordnungen – State building codes define minimum room sizes (varies by Bundesland).
