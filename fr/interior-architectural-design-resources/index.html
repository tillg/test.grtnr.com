Règles d’Aménagement & Dimensions

Livres de Référence (Normes de l’Industrie)

  • Neufert – Bauentwurfslehre / Architects’ Data – La référence allemande définitive pour la planification architecturale. Contient des données métriques complètes sur les tailles de pièces, les dégagements, et les dimensions humaines. Basé sur les normes DIN. 44e édition allemande (2024) disponible.
  • Metric Handbook (Pamela Buxton) – PDF | Équivalent britannique de Neufert. Couvre tous les types de bâtiments avec des données de planification métriques.

Réglementations de Construction Allemandes

  • Wohnflächenverordnung (WoFlV) – Norme allemande de calcul des surfaces habitables. Règles clés : pièces de moins de 1m de hauteur = 0%, 1–2m = 50%, balcons = 25–50%.
  • DIN 277 – Méthode de calcul alternative comptant toutes les surfaces à 100%.
  • Landesbauordnungen – Les codes de construction des États définissent les tailles minimales des pièces (varie selon le Bundesland).
