February 9, 2026
architecture

I want to learn SketchUp. Here’s my list of online resources for beginners.

Official Resources

Resource Format Description
SketchUp Campus Video courses Official learning platform with Fundamentals courses (5.0 rating). Covers all core tools and techniques.
Getting Started in SketchUp Documentation Official guide covering interface navigation, templates, units, toolbars, and preferences.

Free Courses (Structured Learning)

Resource Format Level Notes
MasterSketchUp - SketchUp Free for Beginners Web course Absolute beginner Complete browser-based course, no installation needed. Perfect for first-timers. 2026-02: Did it ✅
LinkedIn Learning - Learning SketchUp Free Video course Beginner Free with library card in many libraries. Instructor: George Maestri.
SketchUp School - Definitive Guide Written guide Beginner Covers 7 critical concepts self-taught users often miss.

YouTube Channels (Video Tutorials)

Channel Focus Best For

Platform What It Offers

Recommended Learning Path

  1. Start with SketchUp Free (browser version, no download)
  2. First course: MasterSketchUp Beginner Course or SketchUp Campus Fundamentals
  3. Practice projects: Follow along with The SketchUp Essentials on YouTube
  4. Reference: Keep SketchUp Help docs bookmarked
